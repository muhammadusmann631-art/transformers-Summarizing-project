# Transformers & Hugging Face: From Zero to Hero

Welcome to the **Transformers Course** repository! This course is a practical guide to mastering the Hugging Face ecosystem, deep learning architectures, and natural language processing (NLP) using modern Transformer models.

From using pre-trained pipelines to fine-tuning custom models on your own datasets, this repository contains clean, ready-to-run Jupyter notebooks and scripts.

---

## 🚀 Course Highlights
*   **Transformer Architecture:** Understanding Attention Mechanisms, Encoder-Decoder setups.
*   **Hugging Face Ecosystem:** Mastering `pipelines`, `datasets`, and the `Hub`.
*   **Tokenization:** Deep dive into Byte-Pair Encoding (BPE), WordPiece, and custom tokenizers.
*   **Fine-Tuning Models:** Custom training using PyTorch and the Hugging Face `Trainer` API.
*   **Tasks Covered:** Text Classification, Named Entity Recognition (NER), Question Answering, and Text Generation.

---

## 🛠️ Tech Stack Used
*   **Frameworks:** Hugging Face (Transformers, Datasets, Evaluate, Accelerate)
*   **Deep Learning:** PyTorch / TensorFlow
*   **Tools:** Jupyter Notebooks, Weights & Biases (for tracking)

---

## 📂 Repository Structure
*   `01_Pipeline_Basics/` - Introduction to out-of-the-box NLP tasks.
*   `02_Tokenizers_and_Datasets/` - How text is processed and fed into models.
*   `03_Fine_Tuning_Custom_Data/` - Training BERT/RoBERTa on custom text datasets.
*   `04_Text_Generation_GPT/` - Working with causal language models and decoding strategies.
*   `notebooks/` - Step-by-step interactive code guides.
